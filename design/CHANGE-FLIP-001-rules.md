# CHANGE-FLIP-001 — 翻牌對戰規則單（定稿待掛）

提出：主策劃（製作人定案＋補針：題庫不限類別，越無厘頭越好）  
給：主程式／介面HUD／美術／品管  
狀態：**部分作廢。** 結算／UX／美術用語以 **CHANGE-FLIP-002-004-rules.md** 為準（少數方喝、選項先亮、Word／Excel）。魔刃 STOP 維持。

## 白話
先出一道荒謬題，下面兩張蓋住的牌。倒數 3 秒一起翻。選錯的人喝酒。罰完點「下一題」；房間要看誰點了、誰沒點，**全員點完**才進下一題。

本模式是第四種玩法，與既有「抽一位／喝杯順序／分隊乾杯」並列；**不發動角色技能**（避免跟選牌搶戲）。

---

## 一局流程（單輪）
1. **出題**：顯示題幹（可附極短補充，一行內）。
2. **蓋牌**：題下兩張牌背朝上（左 A／右 B），暫時看不到正面。
3. **倒數**：3 → 2 → 1（整秒；到 0 當幀翻開）。倒數期間**不可選牌**。
4. **翻牌＋作答窗**：兩張正面亮出；玩家點選其中一張。  
   - 單機傳著玩：當前回合的「作答者」點一張即結算。  
   - 房間：每位玩家各自點一張；未點者顯示「還沒選」。
5. **判定＋喝酒**：對＝歡呼短句、不喝；錯＝該人喝（見下）。可多人同時錯。
6. **下一題**：結算後出現「下一題」鈕。  
   - 單機：點了就進下一題。  
   - 房間：顯示誰已點／誰沒點；**全員都點過「下一題」**才清題、進下一輪（房主無特權跳過，除非斷線規則）。

---

## 題庫來源（越無厘頭越好）
| 項 | 規則 |
|---|---|
| 來源 | 內建題庫 JSON／TS 表（`flipQuestions`），**不限類別** |
| 口味 | 荒謬、錯位、假知識、辦公室鬼打牆、街頭胡謅皆可；**禁止**真歧視／性剝削／鼓吹危險飲酒量 |
| 首包量 | ≥ **40** 題；可重複洗牌，同局盡量不連抽同一題（佇列抽完再洗） |
| 誰寫 | 策劃維護題庫；美術只做牌面框，不審題意 |
| 範例方向 | 「電梯裡先放屁的人要不要道歉？」「周一早上咖啡算早餐嗎？」「老闆說的『找時間聊聊』是吉還是兇？」——答案兩造都歪，只靠預先標好的「正解鍵」 |

每題結構：
```
id, prompt, optionA, optionB, correct: 'A' | 'B', drinkWrong: number（預設 1）
```
`correct`＝預先指定的「這局算對的那面」——**不必真理正確**，只求派對可吵、可笑。

---

## 兩張牌內容
| 牌 | 蓋住時 | 翻開後 |
|---|---|---|
| A（左） | 統一牌背（舊；UX 以 FLIP-004 選項先亮為準） | `optionA` 短文（≤16 字為佳） |
| B（右） | 同上 | `optionB` 短文 |

兩項必須互斥、可點；禁止「以上皆是」當唯一正解除非另一面是明確對照。

---

## 對錯判定
| 情況 | 結果 |
|---|---|
| 選中 `correct` 那面 | **對**；不喝；短句如「漂亮／倖存」 |
| 選另一面 | **錯**；喝 `drinkWrong` 杯（預設 **1**） |
| 作答窗逾時（房間） | 建議 **8s** 未選＝視同錯、喝 1（單機可無逾時，因傳機） |
| 倒數結束前誤觸 | 忽略 |

「一杯」定義跟 RULES-001 P0：開局講好的單位；本模式不另開半杯，除非題目 `drinkWrong: 0.5`。

---

## 單機 vs 房間
| | 單機（一台傳） | 房間（WS） |
|---|---|---|
| 出題／倒數 | 本機 | 房主／伺服權威同步 seed＋題 id＋翻牌時刻 |
| 選牌 | 當前持機者選一次 | 每人各自選；UI 顯示各人已選／未選（可不露選了哪面直到全員選完或逾時） |
| 結果 | 立刻顯示對錯＋喝 | 全員鎖定後一次揭示對錯；錯的人名單高亮 |
| 下一題 | 一人點即進 | **Ready**：每人點「下一題」；名單顯示已點／沒點；齊了才下一題 |
| 斷線 | — | 未重連者 15s 後本輪視為已點下一題（避免卡死）※實作可調 |
| 角色技能 | **不發動** | **不發動** |

---

## 與現有模式關係
模式選單加第四項：**翻牌對戰**。  
不取代抽一位；可同一派對切換。  
不開第四種角色。

---

## 驗收
1. 倒數 3 秒內不能選；到 0 翻牌。  
2. 選錯喝酒、選對不喝；無厘頭題可連續出。  
3. 房間：選牌狀態＋下一題點名狀態都看得到；全員下一題才換題。  
4. 單機可完整走完一輪無需 WS。
