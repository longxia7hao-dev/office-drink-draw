# HUD-PENALTY-001 — 練習模式：人數區↔懲罰鈕中間掛點（HOTFIX）

**狀態：** 線框／掛點可掛  
**案：** 《公司酒局》練習模式（總監 HOTFIX；酒局掛起中僅本 HOTFIX）  
**皮：** 美式嘻哈街頭塗鴉（ART-PENALTY-001）；禁勇者 Q 版  

---

## 白話
組隊／練習畫面上：**人數區**下面、**懲罰主鈕**上面，塞一條「選懲罰」切圖區；點一下換圖＋短動效，讓大家知道這局罰什麼。

---

## 直式區塊（上→下）

| # | 區 | 掛點 | 規格 |
|---|----|------|------|
| 1 | 頂欄 | （既有） | 回上／練習標籤 |
| 2 | **人數區** | `#practice-roster`／既有 `.player-list` | 人數 chips；本 HOTFIX **不改**人數邏輯 |
| 3 | **選懲罰帶** | `#penalty-picker` | **新建**；夾在 2 與 4 之間 |
| 4 | **懲罰／開始鈕** | `#btn-penalty-go`／既有主 CTA | 「用此懲罰開打」類大金鈕；在選懲罰帶**下方** |

## `#penalty-picker` 線框

```
┌─────────────────────────────────┐
│  本局懲罰                        │  ← 小噴漆標
│  ┌─────┐                        │
│  │ IMG │  ← 當前懲罰大圖         │  高約 0.22–0.28H
│  │     │     塗鴉貼紙感           │
│  └─────┘                        │
│  〈 半杯 〉  （名）               │
│  ● ○ ○ ○ ○   五點指示            │
│  [ ← ]              [ → ]        │  或整圖左右滑
└─────────────────────────────────┘
```

### 五態切圖（對 ART-PENALTY-001）
| id | 圖 | 顯示名 |
|----|-----|--------|
| `half` | `penalty-half.svg` | 半杯 |
| `full` | `penalty-full.svg` | 一杯 |
| `fitness` | `penalty-fitness.svg` | 健身 |
| `forehead` | `penalty-forehead.svg` | 額頭 |
| `custom` | `penalty-custom.svg` | 自訂 |

路徑：`public/art/penalty-*.svg`（可被 `.png` 同名覆蓋）。

### 切換動效（短）
- 換張：舊圖 **甩出 120–180ms**（輕旋轉／位移）→ 新圖 **彈入 160–220ms**（貼紙彈）  
- Lottie 可選：之後點名 Lottie 席；先 CSS／現成短動即可  
- 點點指示同步；名稱跟圖一起換  

### 互動
- 左／右鈕或橫滑＝循環五態  
- 點大圖＝也可下一張（可選）  
- 選定值寫入 `practicePenaltyId`；主鈕帶此 id 進練習局

## 不做
不改翻牌少數方規則；不改酒局主流程除非主程式掛本掛點；不套 Word／Excel／勇者立繪。

## 驗收
人數區與懲罰主鈕之間看得到五圖可切；切換有短動效；塗鴉風。
